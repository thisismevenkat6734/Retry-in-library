About Computer Knowledge

Computer Knowledge is an important subject in many competitive examinations. It covers computer fundamentals, hardware, software, operating systems, office applications, networking, internet and cybersecurity.

కంప్యూటర్ పరిజ్ఞానం అనేక పోటీ పరీక్షల్లో ముఖ్యమైన అంశం. కంప్యూటర్ ప్రాథమిక అంశాలు, హార్డ్‌వేర్, సాఫ్ట్‌వేర్, ఆపరేటింగ్ సిస్టమ్స్, ఇంటర్నెట్ మరియు సైబర్ సెక్యూరిటీ ఇందులో ఉంటాయి.

1. Computer Fundamentals

Computer: An electronic device that accepts data, processes it according to instructions, stores it and produces information.

కంప్యూటర్: డేటాను స్వీకరించి, సూచనల ప్రకారం ప్రాసెస్ చేసి, సమాచారాన్ని అందించే ఎలక్ట్రానిక్ పరికరం.

Basic Characteristics

  • Speed – వేగం
  • Accuracy – ఖచ్చితత్వం
  • Storage – నిల్వ సామర్థ్యం
  • Diligence – అలసట లేకుండా పనిచేయడం
  • Automation – స్వయంచాలకంగా పనిచేయడం
  • Versatility – బహుముఖ వినియోగం

Basic Computer Cycle

Input → Processing → Output → Storage

ఉదాహరణ: Keyboard ద్వారా డేటా ఇవ్వడం, CPU ద్వారా ప్రాసెస్ చేయడం, Monitor పై ఫలితం చూపించడం.

Types of Computers

  • Supercomputer – సూపర్ కంప్యూటర్
  • Mainframe Computer – మెయిన్‌ఫ్రేమ్ కంప్యూటర్
  • Minicomputer – మినీ కంప్యూటర్
  • Microcomputer – మైక్రో కంప్యూటర్
  • Embedded Computer – ఎంబెడెడ్ కంప్యూటర్

2. Computer Hardware

Hardware refers to the physical components of a computer that can be seen and touched.

కంప్యూటర్‌లో చూడగలిగే మరియు తాకగలిగే భౌతిక భాగాలను హార్డ్‌వేర్ అంటారు.

Input Devices

  • Keyboard – కీబోర్డ్
  • Mouse – మౌస్
  • Scanner – స్కానర్
  • Microphone – మైక్రోఫోన్
  • Webcam – వెబ్‌క్యామ్
  • Barcode Reader – బార్‌కోడ్ రీడర్
  • Touchscreen – టచ్‌స్క్రీన్

Output Devices

  • Monitor – మానిటర్
  • Printer – ప్రింటర్
  • Speaker – స్పీకర్
  • Projector – ప్రొజెక్టర్
  • Plotter – ప్లాటర్

Central Processing Unit (CPU)

CPU is commonly called the brain of the computer. It executes instructions and performs processing operations.

  • ALU – Arithmetic Logic Unit
  • CU – Control Unit
  • Registers – Very small, fast storage locations inside the CPU

3. Software and Operating Systems

Software is a collection of programs and instructions that tell a computer what to do.

కంప్యూటర్‌కు ఏమి చేయాలో సూచించే ప్రోగ్రాములు మరియు ఆదేశాల సమాహారమే సాఫ్ట్‌వేర్.

Types of Software

  • System Software – సిస్టమ్ సాఫ్ట్‌వేర్
  • Application Software – అప్లికేషన్ సాఫ్ట్‌వేర్
  • Utility Software – యుటిలిటీ సాఫ్ట్‌వేర్
  • Device Drivers – పరికరాలను నిర్వహించే డ్రైవర్లు

Operating System (OS)

An operating system manages computer hardware, software resources and user interaction.

ఆపరేటింగ్ సిస్టమ్ కంప్యూటర్ హార్డ్‌వేర్, సాఫ్ట్‌వేర్ వనరులను నిర్వహిస్తుంది.

Examples: Windows, Linux, macOS, Android and iOS.

Important OS Functions

  • Process Management
  • Memory Management
  • File Management
  • Device Management
  • Security and User Management

4. Computer Memory and Storage

Computer memory stores data, instructions and processing results.

Primary Memory

  • RAM – Random Access Memory; generally volatile.
  • ROM – Read Only Memory; generally non-volatile.
  • Cache Memory – High-speed memory used to reduce data access time.
  • Registers – Very fast storage inside the processor.

Secondary Storage

  • HDD – Hard Disk Drive
  • SSD – Solid State Drive
  • USB Flash Drive – పెన్ డ్రైవ్
  • Memory Card – మెమరీ కార్డ్
  • Optical Disc – CD, DVD and Blu-ray Disc

Data Units

  • Bit – Binary Digit
  • Byte – 8 bits
  • Kilobyte (KB)
  • Megabyte (MB)
  • Gigabyte (GB)
  • Terabyte (TB)

Exam note: Traditional textbook conversions often use 1 KB = 1024 bytes. In modern storage standards, decimal and binary units are distinguished.

5. Office Applications

Office applications are used to create documents, spreadsheets and presentations.

Word Processing

  • Creating and editing documents
  • Text formatting and page layout
  • Tables, headers and footers
  • Spell checking and printing

Spreadsheet Applications

  • Rows, columns and cells
  • Formulas and functions
  • Charts and data analysis
  • Sorting and filtering

Presentation Applications

  • Slides and layouts
  • Text, images and charts
  • Transitions and animations
  • Slide show presentation

Examples: Microsoft Word, Excel, PowerPoint, LibreOffice Writer, Calc and Impress.

6. Internet and Email

The Internet is a global network of interconnected computer networks that communicate using standard protocols.

Important Terms

  • WWW – World Wide Web
  • URL – Uniform Resource Locator
  • HTTP – Hypertext Transfer Protocol
  • HTTPS – HTTP Secure
  • HTML – Hypertext Markup Language
  • Browser – Software used to access websites
  • Search Engine – Service used to find information online
  • ISP – Internet Service Provider

Email

  • To – Main recipient
  • CC – Carbon Copy
  • BCC – Blind Carbon Copy
  • Attachment – File sent with an email
  • Spam – Unwanted or unsolicited messages
  • Phishing – Fraudulent attempt to steal sensitive information

7. Computer Networking

A computer network connects devices to share information and resources.

Types of Networks

  • PAN – Personal Area Network
  • LAN – Local Area Network
  • MAN – Metropolitan Area Network
  • WAN – Wide Area Network

Networking Devices

  • Router – Routes data between networks
  • Switch – Connects devices within a local network
  • Hub – Broadcasts incoming data to connected ports
  • Modem – Modulates and demodulates signals
  • Repeater – Regenerates signals
  • Access Point – Provides wireless network access

Important Protocols

  • TCP/IP – Core Internet communication protocols
  • DNS – Domain Name System
  • FTP – File Transfer Protocol
  • SMTP – Simple Mail Transfer Protocol
  • POP3 and IMAP – Email retrieval protocols

8. Cyber Security

Cybersecurity protects computers, networks, accounts and information from unauthorized access and digital attacks.

డిజిటల్ దాడులు మరియు అనధికార ప్రవేశం నుంచి కంప్యూటర్లు, నెట్‌వర్క్‌లు, సమాచారాన్ని రక్షించడమే సైబర్ సెక్యూరిటీ.

Common Threats

  • Virus – వైరస్
  • Worm – వార్మ్
  • Trojan Horse – ట్రోజన్ హార్స్
  • Ransomware – రాన్సమ్‌వేర్
  • Spyware – స్పైవేర్
  • Phishing – ఫిషింగ్
  • Social Engineering – సోషల్ ఇంజినీరింగ్

Safety Practices

  • Use strong and unique passwords.
  • Enable multi-factor authentication.
  • Do not open suspicious links or attachments.
  • Keep software and operating systems updated.
  • Back up important data regularly.
  • Never share OTPs, PINs or passwords.

9. Database Management

A database is an organized collection of data that can be stored, accessed and managed efficiently.

Important Terms

  • DBMS – Database Management System
  • RDBMS – Relational Database Management System
  • Table – Collection of related records
  • Record – A row in a table
  • Field – A column or data attribute
  • Primary Key – Uniquely identifies a record
  • Foreign Key – Establishes a relationship between tables
  • SQL – Structured Query Language

Examples: MySQL, PostgreSQL, SQLite, Oracle Database and Microsoft SQL Server.

10. Programming Basics

Programming is the process of writing instructions that a computer can execute to perform tasks.

Basic Concepts

  • Algorithm – Step-by-step problem-solving procedure
  • Flowchart – Diagram representing a process
  • Variable – Named storage for a value
  • Constant – Value that does not change during its defined use
  • Loop – Repeats instructions
  • Conditional Statement – Executes instructions based on a condition
  • Debugging – Finding and fixing errors

Programming Languages

  • C and C++
  • Java
  • Python
  • JavaScript
  • PHP

11. Modern Technology

  • Artificial Intelligence (AI) – కృత్రిమ మేధస్సు
  • Machine Learning (ML) – మెషిన్ లెర్నింగ్
  • Cloud Computing – క్లౌడ్ కంప్యూటింగ్
  • Internet of Things (IoT) – ఇంటర్నెట్ ఆఫ్ థింగ్స్
  • Blockchain – బ్లాక్‌చెయిన్
  • Big Data – బిగ్ డేటా
  • Virtual Reality (VR) – వర్చువల్ రియాలిటీ
  • Augmented Reality (AR) – ఆగ్మెంటెడ్ రియాలిటీ
  • Digital Payments – డిజిటల్ చెల్లింపులు
