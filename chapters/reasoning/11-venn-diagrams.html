Venn Diagrams
వెన్ చిత్రాలు

Venn Diagram అనేది రెండు లేదా అంతకంటే ఎక్కువ సమితుల (Sets) మధ్య ఉన్న సంబంధాలను వృత్తాల ద్వారా చూపించే పద్ధతి. ఏ సమూహాలు ఒకదానిలో మరొకటి ఉంటాయి, ఏవి కొంతవరకు కలుస్తాయి, ఏవి పూర్తిగా వేరుగా ఉంటాయి అనే విషయాలను సులభంగా అర్థం చేసుకోవడానికి ఇది ఉపయోగపడుతుంది.

Learning goals: set relationships గుర్తించడం, రెండు/మూడు సమితుల diagrams అర్థం చేసుకోవడం, only/both/neither లెక్కించడం, union–intersection సూత్రాలు ఉపయోగించడం.

1. Venn Diagram అంటే ఏమిటి? | Meaning

ఒక పెద్ద సమూహం లేదా Universal Setలో చిన్న చిన్న సమూహాలు ఉంటాయి. ప్రతి సమూహాన్ని సాధారణంగా ఒక వృత్తంతో సూచిస్తారు. వృత్తాలు కలిసే భాగం common membersను సూచిస్తుంది.

Set / సమితి

ఒక నిర్దిష్ట లక్షణం కలిగిన వస్తువులు లేదా వ్యక్తుల సమూహం.

Element / సభ్యుడు

ఒక సమితిలోని ఒక్క వస్తువు లేదా వ్యక్తి.

Universal Set (U)

ప్రశ్నలో పరిశీలిస్తున్న మొత్తం పరిధిలోని సభ్యుల సమితి.

Subset / ఉపసమితి

Aలోని ప్రతి సభ్యుడు Bలో కూడా ఉంటే A, Bకు ఉపసమితి.

A ⊆ B అంటే Aలోని ప్రతి సభ్యుడు Bలో ఉంటాడు. A, Bలో పూర్తిగా ఉంటుంది.

“All roses are flowers” అంటే Roses సమితి Flowers సమితిలో పూర్తిగా ఉంటుంది. కానీ అన్ని Flowers కూడా Roses అని కాదు.

3. Basic Venn Diagram Types | ప్రాథమిక చిత్రాలు

A ⊆ B – Subset

_____________ / B \ | _______ | | / A \ | | \_______/ | \_____________/

A మొత్తం Bలో ఉంటుంది.

A ∩ B = ∅ – Disjoint

( A ) ( B ) separate sets

రెండు సమితుల్లో common సభ్యులు లేరు.

A ∩ B – Overlap

______ ______ / \/ \ / A X B \ \ /\ / \______/ \____/

కలిసిన భాగంలో రెండు సమితులకు చెందిన సభ్యులు ఉంటారు.

Three sets

( A ) ( B X C ) central = A∩B∩C

మూడు వృత్తాల common భాగం A∩B∩C.

జాగ్రత్త: circles ఆకారం లేదా పరిమాణం సంఖ్యలను సూచించవు. ప్రశ్నలో ఇచ్చిన సంబంధాలనే సూచిస్తాయి.

4. Classification Questions | సమూహాల వర్గీకరణ

పదాల మధ్య ఉన్న సహజమైన set relationshipను గుర్తించి సరైన diagramను ఎంచుకోవాలి. “All”, “Some”, “No” వంటి పదాల అర్థాన్ని స్పష్టంగా చూడాలి.

Example: Teachers, Women, Mothers

మాతృమూర్తులందరూ మహిళలే. ఉపాధ్యాయుల్లో పురుషులు, మహిళలు ఉండవచ్చు. కొంతమంది మహిళా ఉపాధ్యాయులు తల్లులు కావచ్చు. కాబట్టి Mothers ⊂ Women; Teachers సమితి Womenతో overlap అవుతుంది.

5. Two-Set Venn Diagrams | రెండు సమితుల చిత్రాలు

రెండు సమితులు A, B ఉన్నప్పుడు నాలుగు ప్రాంతాలు ఉంటాయి:

  1. A only: Aలో ఉండి Bలో లేనివి.
  2. B only: Bలో ఉండి Aలో లేనివి.
  3. Both: A, B రెండింటిలోనూ ఉన్నవి (A∩B).
  4. Neither: A లేదా Bలో లేనివి; కానీ Universal Setలో ఉన్నవి.
Universal Set (U) ___________________________________ | _______ _______ | | / \_____/ \ | | / A only \Both/ B only \ | | \ / \ / | | \_______/ \_______/ | | Neither region | |___________________________________|

“Only A” అంటే common భాగాన్ని తీసివేయాలి. “At least one” అంటే union. “Neither” అంటే మొత్తం నుంచి unionను తీసివేయాలి.

6. Important Formulas | ముఖ్యమైన సూత్రాలు

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

రెండు సమితుల్లో కనీసం ఒకదానిలో ఉన్న సభ్యుల సంఖ్య. Common సభ్యులు రెండుసార్లు లెక్కవుతారు కాబట్టి ఒకసారి తీసివేయాలి.

A only = n(A) − n(A ∩ B)
B only = n(B) − n(A ∩ B)
Neither = n(U) − n(A ∪ B)
Exactly one = n(A) + n(B) − 2n(A ∩ B)

“Exactly one” అంటే A మాత్రమే లేదా B మాత్రమే; common భాగం ఇందులో ఉండదు.

n(A ∪ B ∪ C) = n(A)+n(B)+n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C)

మూడు సమితుల unionలో pairwise intersectionsను తీసివేసి, central common partను మళ్లీ కలపాలి.

7. Solved Examples | పరిష్కరించిన ఉదాహరణలు

Example 1 – At least one

30 మంది Tea ఇష్టపడతారు; 20 మంది Coffee ఇష్టపడతారు; 10 మంది రెండూ ఇష్టపడతారు.

n(T∪C) = 30 + 20 − 10 = 40.

Example 2 – Neither

మొత్తం 50 మంది. Maths=28, Science=22, రెండూ=8.

Union=28+22−8=42. Neither=50−42=8.

Example 3 – Exactly one

English=50, Hindi=40, రెండూ=15.

Only English=35; only Hindi=25; exactly one=35+25=60.

Example 4 – Find intersection

n(A)=25, n(B)=23, n(A∪B)=42.

Intersection=25+23−42=6.

Example 5 – Three sets

A=40, B=35, C=30; pairwise intersections=12,10,8; triple intersection=4.

Union=40+35+30−12−10−8+4=79.

8. Three-Set Problems | మూడు సమితుల ప్రశ్నలు

మూడు circlesలో ఏడు అంతర్గత regions ఉంటాయి: A only, B only, C only, A∩B only, B∩C only, C∩A only, A∩B∩C. వీటికి బయట ఉన్న ప్రాంతం neither of all three.

  1. ముందుగా మూడు సమితుల common కేంద్ర భాగాన్ని గుర్తించండి.
  2. Pairwise “both” సంఖ్యలు central partను కూడా కలిగి ఉన్నాయా చూడండి.
  3. Pairwise-only ప్రాంతం కావాలంటే pairwise total నుంచి central భాగాన్ని తీసివేయండి.
  4. చివరగా అన్ని regionsను కలిపి union కనుగొనండి.
A∩B only = n(A∩B) − n(A∩B∩C)

ఉదా: A, B రెండింటిలో 12 మంది; మూడింటిలో 4 మంది ఉంటే A మరియు Bలో మాత్రమే = 12−4 = 8 మంది.

9. Common Mistakes & Shortcuts | తప్పులు మరియు చిట్కాలు

  • Double counting: A, B సంఖ్యలను నేరుగా కలిపి common membersను రెండుసార్లు లెక్కించవద్దు.
  • Only vs Both: “A only” అంటే A మొత్తం కాదు; intersection తీసివేయాలి.
  • Neither: Total నుంచి union తీసివేయాలి.
  • Exactly one: Common సభ్యులను పూర్తిగా మినహాయించాలి.
  • Three-set overlap: Pairwise countsలో central members ఉన్నాయా గుర్తించండి.
  • Diagram assumptions: circles పరిమాణం చూసి సంఖ్యలను ఊహించవద్దు.
  • Subset reversal: A ⊆ B అంటే B ⊆ A అని కాదు.
Fast method: “At least one” → add sets and subtract overlap. “Neither” → Total − At least one. “Only” → Set total − overlap.

10. Exam Strategy | పరీక్షలో అనుసరించాల్సిన విధానం

  1. ప్రశ్నలోని సమితుల పేర్లు వ్రాయండి.
  2. పద సంబంధ ప్రశ్న అయితే subset / overlap / disjoint రకం నిర్ణయించండి.
  3. సంఖ్యా ప్రశ్న అయితే Total, A, B, Both, Neither విలువలను వేరు చేయండి.
  4. అవసరమైన సూత్రాన్ని ఎంచుకోండి.
  5. సంఖ్యలను substitute చేసి క్రమంగా లెక్కించండి.
  6. సమాధానం మొత్తం సంఖ్య కంటే ఎక్కువగా లేదో, negative కాకపోయిందో తనిఖీ చేయండి.

ఈ అధ్యాయంలోని ప్రశ్నలు సాధారణ పోటీ పరీక్షల నమూనాలను బట్టి రూపొందించిన practice questions; ఇవి నిర్దిష్ట పరీక్షల్లో వచ్చిన అసలు ప్రశ్నలని భావించకండి.
